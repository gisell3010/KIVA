# Documentación de KIVA

KIVA es una plataforma de organización de viajes grupales desarrollada con Angular, FastAPI y PostgreSQL. Esta carpeta reúne la documentación técnica, los manuales por rol y los diagramas del modelo de datos.

| Documento | Contenido |
|---|---|
| [Arquitectura](architecture/README.md) | Componentes, persistencia e integración. |
| [API](api/README.md) | Recursos REST, autenticación y autorización. |
| [Modelo de datos](database/README.md) | Diagramas y referencia del esquema. |
| [Permisos](PERMISSIONS.md) | Roles globales, contextuales y reglas de acceso. |
| [Manuales](manuals/README.md) | Operaciones de usuarios, soporte y administración. |
| [Despliegue](DEPLOYMENT.md) | Servicios, almacenamiento e infraestructura. |

La instalación local se describe en el [README principal](../README.md). Los detalles de configuración están en [Backend](../backend/README.md), [Frontend](../frontend/README.md) y [Base de datos](../database/README.md).
